# spx-exception-handling

GAS WebApp xử lý ngoại lệ (mất bill SPX): tạo mã Box/Item nội bộ, lưu ảnh Drive, Resolve bill, Thanh Lý theo lô, in QR, quét camera + súng.

Workflows giống repo `spx-diem-danh`:
- `.github/workflows/deploy.yml` — push `main` → `clasp push` + tạo version + redeploy production `/exec` (cần secrets `GAS_SCRIPT_ID`, `CLASPRC_JSON`).
- `.github/workflows/test.yml` — CI gate: `npm test` + Python `unittest` + `build:local` + `test:chrome`.

## Setup sau khi tạo repo

1. Vào repo Settings → Secrets and variables → Actions → New repository secret:
   - `GAS_SCRIPT_ID` = ID Apps Script project (đã set sẵn khi tạo repo).
   - `CLASPRC_JSON` = nội dung `~/.clasprc.json` (copy từ máy đã `clasp login`, hoặc từ repo cũ).
2. Push lên `main` → kiểm tra tab Actions (Deploy + Test chạy).
3. Mở Apps Script project → Deploy → kiểm tra `/exec` đã lên version mới.

## Setup GAS (Script Properties)

- `SPREADSHEET_ID` = ID Spreadsheet DB (không hardcode — luật 1). Sheet tự tạo: `Items` (12 cột theo `docs/db-schema.md`), `Photos`, `ActivityLog`, `PrintedCodes` (giữ chỗ mã in hàng loạt: `code, printed_at, printed_by, kind`).
- `FOLDER_ID` = ID thư mục Drive chứa ảnh (server tạo subfolder `YYYY-MM`). Lấy từ URL folder `drive.google.com/drive/folders/<ID>`, điền vào Script Properties, không hardcode/không gửi qua chat.
- `ADMIN_EMAILS` = email ADMIN seed, cách nhau dấu phẩy (khi sheet `Users` còn trống thì các email này là ADMIN, còn lại STAFF; có ADMIN rồi thì phân quyền tiếp ở trang Quyền Truy Cập).

## Contract

- Mã mới: `Box.DD-MM-YYYY.seq` / `Item.DD-MM-YYYY.seq` (seq/ngày từ 1, server cấp trong lock). Mã cũ `BOX.DDMMYYYY.NN` vẫn đọc được.
- Trạng thái canonical: `chua_xu_ly` (hiển thị Lưu kho) · `da_tim_bill` (hiển thị Resolve) · `thanh_ly` (hiển thị Thanh Lý) + `da_cho_di`/`tieu_huy` (import cũ). Map SSOT tại `scripts/import-csv.js:STATUS_RULES`, mirror `api/logic.py` + `Code.gs`.
- API (`google.script.run`): `listItems(limit — tối đa 100 dòng đầu, đơn mới insert ở dòng 2 nên luôn mới nhất)` · `getItem(code)` (kèm history Chi tiết trạng thái — mốc chuyển trạng thái có `bill` + `extras`/`slots` ảnh) · `previewCode(kind)` (nhảy qua mã đã giữ chỗ in) · `previewBulkCodes(kind, count)` (sinh dãy liên tục, `count` chặn 1–10, append giữ chỗ vào `PrintedCodes` trong lock) · `createBox(p)` · `createItem(p)` (`p={description, note, outer, product, extras[], customCode?}` (mã ghi đè từ nút Sửa/Ok — đúng dạng `Box./Item.` khớp loại, trùng thì server báo lỗi), trả thêm `item` để client unshift cache không reload) — Box bắt buộc ngoại quan + sản phẩm, Item bắt buộc 1 ảnh sản phẩm, ảnh 3 tùy chọn · `resolveItem(code, bill)` · `liquidateBatch(codes[], liqCode)` · `me()` · `listUsers()` · `setUserRole(email, role)` · `adminEditItem(p)` (ADMIN sửa trong modal Edit điền sẵn: mô tả/ghi chú/xóa/thêm ảnh (unlink giữ file gốc, ép đủ ảnh theo loại, tổng ≤3) + đổi trạng thái (`p={code, description, note, deleteSlots[], addPhotos[], toStatus, bill}` — bill bắt buộc khi sang Resolve/Thanh Lý; log đủ mốc (mốc đổi trạng thái trong Edit ghi `ADMIN đổi trạng thái`, không ghi email ADMIN) + mốc `ADMIN chỉnh sửa …` liệt kê trường đổi)) · `addAdmin(email)` (thêm luôn ADMIN) · `deleteUser(email)` (xóa user, chặn ADMIN cuối/tự xóa) · `fixPhotoSharing()` (ADMIN share lại toàn bộ ảnh cũ) · `getPhoto(fileId)` (fallback khi thumbnail Drive bị chặn như Safari: server đọc ảnh bằng quyền deploy rồi trả base64, client cache memory, chỉ gọi khi `<img>` lỗi). Mọi response `{ok, data/error}`.
- Luồng: Chính (scan → click ảnh → chi tiết → bấm Resolve thì nút thành Confirm, ô bill nằm trên (bắt buộc) → Confirm ghi timeline Chi tiết trạng thái đủ giờ·email·token·bill; đơn Resolve/Thanh Lý đổi trạng thái trong Edit của ADMIN, không còn nút Mở lại; giữ cache 100 đầu ở client (merge theo `code`, không reload full; chi tiết mở tức thì từ cache list (ảnh/thông tin có ngay, lịch sử về sau); đơn đã mở trong 5 phút mở lại zero call, quá hạn mới refresh nền; tự động tải mới mỗi 5 phút + nút ↻ Mới để bắt đơn từ máy khác; client không đẩy ngược cache, chỉ gửi delta), mọi thao tác hiện trước từ cache local (mốc `đang đồng bộ`), rồi mới đẩy server — lỗi thì rollback + báo lỗi thật, không nuốt) · Create 2 bước (Create New Task: Thanh Lý → sang trang Thanh Lý; Non-AWB Recovery → chọn BOX/ITEM → form mô tả + ảnh theo loại (Box đủ 2 ảnh, Item 1 ảnh sản phẩm; ô mã server cấp có nút Sửa/Ok để ghi đè — mobile ấn Sửa mở camera quét ngay), xong hiện QR trên mobile để in từ máy tính (khổ 4x6in, không tự bật hộp thoại in; Confirm xong giữ nguyên ảnh + dữ liệu + đúng mã vừa tạo, nút Confirm khóa thành Đã lưu ✓, chỉ bấm ＋ Tạo tiếp mới reset sang mã mới)) · Thanh Lý kiểu SPX (ô scan gọn trái, mã vào bảng chi tiết Mã Đơn/Loại/Mô tả có Total + xóa từng dòng, lọc trùng/Đã Resolve/Đã Thanh Lý → Next → mã `SPXVN...` bắt buộc → Confirm chốt lô + reset).
- Quét: camera `html5-qrcode` (chỉ 4 định dạng QR + Code128/Code39/EAN, khai báo ở **constructor** `new Html5Qrcode(id,cfg)` vì lib bỏ qua `formatsToSupport` trong `start()`; fps 25, vùng quét ~92%x88% khung hình để không cắt QR vuông, không decode lại ảnh lật ngược, xin luồng 1080p + bật autofocus liên tục, nút 🔦 Đèn khi camera hỗ trợ pinh sáng; nút Quét chỉ hiện mobile; trong GAS iframe tự mở popup quét top-level dùng chung config, kẹt thì bấm Chụp ảnh decode file; Thanh lý quét liên tục không đóng camera) + súng = Enter trên ô scan (4 điểm: tìm kiếm/thanh lý/bill Resolve/tab In Mã). Form Resolve giữ nguyên khi dữ liệu nền về. In: `window.print()` khổ tem nhiệt 4x6in (`@page { size: 4in 6in }`, QR + tên mã; Box/Item đều có nút In Mã — nút in ẩn trên mobile, chỉ hiện trên PC). Tab In Mã kiểu SPX (nút 🖨 In Mã cạnh + Create vào thẳng tab, ẩn trên mobile → 2 thẻ: In 1 Mã (scan đúng `Box./Item.` là tự in, cả 2 loại) / In Nhiều Mã (chọn Box/Item → server giữ chỗ 10 mã trong `PrintedCodes` + tự in cả 10 bằng 1 lệnh in khổ 4x6in, không xác nhận thêm)).

- Phân quyền: STAFF chỉ tạo/Resolve/Thanh Lý khi còn Lưu kho, không có UI sửa (đơn xong bị khóa) · ADMIN sửa mọi task trong modal Edit (mô tả/ghi chú/ảnh + đổi trạng thái Resolve ⇄ Thanh Lý ⇄ Lưu kho, bill bắt buộc khi sang Resolve/Thanh Lý, log timeline đầy đủ) + quản lý ở tab Role (chỉ ADMIN thấy). Seed ADMIN từ Script Properties `ADMIN_EMAILS`. Ảnh upload tự share công khai, rớt về nội bộ domain khi bị chặn (xem bằng email công ty); share lỗi vẫn lưu đơn + báo rõ. Log sheet ghi gọn `Tạo mới` (toast lúc tạo vẫn báo khi share rớt). Chi tiết Item chỉ hiện Ảnh sản phẩm (Box mới hiện Ảnh ngoại quan). Tài khoản deploy (`Session.getEffectiveUser`, xem ở tab Role) phải là email công ty thì share nội bộ mới được.
- Ngày giờ: sheet để locale US nên mọi cột ngày (`Items.created_at`, `ActivityLog.at`, `Photos.uploaded_at`, `PrintedCodes.printed_at`, `Users.added_at`) ghi dạng text `dd/MM/yyyy HH:mm:ss` kèm dấu `'` (không để Sheets tự parse); đọc đối chiếu ngày trong mã (`parseCreatedSmart_`/`parse_created_smart` — chuỗi đảo ngày/tháng mà khớp ngày trong mã thì lấy theo mã, còn lại giữ cách đọc VN cũ). Hiển thị web giữ nguyên `dd/MM/yyyy HH:mm:ss`.
- UI: bố cục theo mẫu AppSheet gallery (app đang dùng nội bộ): **thẻ ảnh vuông chiếm toàn card + caption mã đơn dưới ảnh + chip trạng thái overlay góc ảnh** (mobile 2 cột, ảnh lỗi hiện `Không tải được ảnh`, trống hiện `Không có ảnh`), desktop có **sidebar trái** (Danh sách/Thanh lý/Role) + **panel chi tiết bên phải dạng drawer không modal** (không phủ mờ lưới — header dính khi cuộn + ảnh gộp dải ngang 3 cột có fallback + nút `Thử lại`, bấm ảnh phóng lightbox nền đen giữa màn hình (zoom ＋/－, kéo pan, Esc/nền đen đóng, không mở tab mới), ngày tách dòng; card Chi tiết trạng thái (timeline giờ·email·token màu đồng bộ·mã bill, có đếm)); đang mở vẫn click ẢNH thẻ khác để đổi nội dung trực tiếp (bấm caption chỉ báo nhắc), nút ‹ › chuyển đơn trong bộ lọc, ⤢ nới rộng panel, đóng thì trượt ẩn sang phải và lưới tự nở lại), ô tìm kiếm trên header căn giữa thật (grid 3 cột, viền cam nhạt; placeholder “Nhập thông tin để tìm kiếm...”, gõ lọc trực tiếp theo mã+mô tả không giới hạn ngày; ngay dưới là thanh Display Range (trái: icon ⓘ nền nhạt + ngày + Edit một hàng, chú thích một mạch — mobile ẩn chú thích; phải: nút 🖨 In Mã + ＋ Create cỡ to trong thanh; mặc định 30 ngày gần nhất, Edit tối đa 60 ngày, chỉ lọc lưới danh sách — lưới trống do Range hiện hộp trống kèm đếm đơn ngoài phạm vi + nút Xem tất cả (tìm kiếm chữ vẫn bypass ngày) — quá 100 đơn thì đơn ngoài cache 100 không hiện, nút filter màu theo trạng thái, Enter/bắn súng mở đơn; quét camera ô tìm kiếm chính chỉ điền + lọc, không tự mở chi tiết — bản mobile giữ thanh điều hướng đáy, chi tiết mở bottom sheet).
